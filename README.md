## 🌟 Главные особенности

* 💎 **Премиум-поддержка клиента Karing**:
  * Пакеты и одиночные серверы оптимизированы для мгновенного добавления в **Karing** (iOS, Android, Windows, macOS).
  * Полная совместимость с **Hiddify**, **v2rayTUN**, **v2rayN**, **Streisand**, **sing-box** и **NekoBox**.
* 📦 **Интеллектуальное разделение по 60 ключей**:
  * Почему 60? Импорт 1000+ серверов разом подвешивает мобильные клиенты и быстро сажает батарею при фоновом замере пинга. Пачки по 60 ключей дают идеальный баланс отказоустойчивости и высокой скорости работы приложения.
  * Файл [`docs/working_keys.txt`](docs/working_keys.txt) снабжён понятными заголовками `# SCK ПАКЕТ #N (60 КЛЮЧЕЙ)`.
  * Отдельные файлы пакетов в папке [`docs/chunks/`](docs/chunks/) (`part_1.txt`, `part_2.txt`, ...) можно скачать или скопировать в один клик.
* 🍎 **Веб-интерфейс по стандартам Apple iOS / HIG**:
  * **0 эмодзи-глифов**: собственная векторная библиотека SVG-флагов гарантирует, что флаги никогда не превратятся в текстовую кашу (`LTEELV`, `FI`, `DE`) на Windows или Linux.
  * **Стек шрифтов Apple SF Pro & SF Mono**.
  * **Матовое стекло (Glassmorphism)** с аппаратным размытием `backdrop-filter: blur(24px)`.
  * **Сегментированные переключатели iOS** с плавными анимациями и тактильным откликом при нажатии.
  * **Адаптивность**: поддержка Safe Area (Dynamic Island, Notch, Home Bar) на iPhone и iPad.
* ⚡ **Диагностика серверов в реальном времени**:
  * Автоматический парсинг параметров: протокол, безопасность (`Reality` / `TLS`), транспорт (`gRPC` / `TCP` / `WebSocket`), `SNI` и `Flow`.
  * Замер реального времени отклика (TCP-пинг от 2.2 мс) и времени непрерывной работы в сети (Uptime).
  * Рейтинговые медали ТОП-3 (золото, серебро, бронза) для самых быстрых серверов в каждой локации.
* 🌐 **Категории доступа**:
  * **Обычный VPN** (полный туннель): Эстония, Финляндия, Германия, Швеция, Нидерланды, Польша и др.
  * **Белые списки** (туннелирование только заблокированных ресурсов для максимальной скорости).

## 🚀 Пошаговое руководство по развёртыванию (Туториал)

Вы можете опубликовать свой сервис **SCK** в интернете совершенно бесплатно за пару минут.

### Вариант А. Публикация через GitHub Pages (100% бесплатно + автообновление)

Это основной и самый простой способ: GitHub будет **сам каждые 30 минут** запускать чекер, отбирать свежие серверы и обновлять ваш сайт без включённого компьютера.

#### Шаг 1. Создание репозитория
1. Откройте [github.com](https://github.com/) и войдите в свой аккаунт.
2. Нажмите **New repository** (или зелёную кнопку «New»).
3. Введите название репозитория: `sck-checker`.
4. Выберите тип: **Public**.
5. Галочки добавления README и .gitignore **не ставьте** (они уже настроены в проекте).
6. Нажмите **Create repository**.

#### Шаг 2. Отправка проекта в репозиторий
Откройте терминал в папке проекта `C:\Users\snek\Desktop\vless-checker-main` и выполните:
```bash
git remote add origin https://github.com/ВАШ_ЛОГИН/sck-checker.git
git push -u origin main
```
> *(Если система запросит авторизацию — нажмите «Sign in with browser»)*.

#### Шаг 3. Включение сайта
1. В репозитории откройте вкладку **Settings** (Настройки).
2. Слева перейдите в раздел **Pages**.
3. В блоке *Build and deployment* выберите:
   * **Source**: `Deploy from a branch`
   * **Branch**: `main`
   * **Folder**: `/docs`
4. Нажмите **Save**. Ссылка на ваш сайт появится вверху страницы (`https://ВАШ_ЛОГИН.github.io/sck-checker/`).

#### Шаг 4. Включение автоматического обновления ключей
1. В том же окне настроек перейдите в **Actions** → **General**.
2. Прокрутите страницу вниз до пункта **Workflow permissions**.
3. Выберите пункт **Read and write permissions** *(чтобы робот мог сохранять свежие ключи)*.
4. Нажмите **Save**.

> [!TIP]
> Теперь GitHub Actions каждые 30 минут по расписанию запускает [`.github/workflows/check_keys.yml`](.github/workflows/check_keys.yml), отбирает рабочие ключи, формирует пакеты по 60 штук и обновляет сайт!

### Вариант Б. Связка GitHub + Cloudflare Pages (Максимальная скорость в РФ)

Сеть **Cloudflare Pages** открывается в России быстрее, чем GitHub Pages, даёт красивый адрес `https://sck.pages.dev` и защиту от любых атак.

1. Опубликуйте код на GitHub (выполните Шаги 1 и 2 из Варианта А).
2. Зайдите на [dash.cloudflare.com](https://dash.cloudflare.com/) (бесплатная регистрация).
3. Перейдите в раздел **Workers & Pages** → нажмите **Create application** → вкладка **Pages**.
4. Нажмите кнопку **Connect to Git** и выберите ваш репозиторий `sck-checker`.
5. В параметрах сборки укажите:
   * **Build command**: *оставьте пустым*
   * **Build output directory**: напишите **`docs`**
6. Нажмите **Save and Deploy**.

> [!NOTE]
> При каждом обновлении ключей на GitHub (каждые 30 минут) Cloudflare Pages сам подхватит изменения и мгновенно обновит сайт по всему миру!

### Вариант В. Развёртывание на своём VPS (Ubuntu / Debian)

Если вы хотите развернуть проект на собственном виртуальном сервере:

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/ВАШ_ЛОГИН/sck-checker.git /var/www/sck
   cd /var/www/sck
   pip install requests
   ```
2. Настройте веб-сервер Nginx:
   ```nginx
   server {
       listen 80;
       server_name sck.yourdomain.com;
       root /var/www/sck/docs;
       index index.html;
   }
   ```
3. Настройте автообновление в планировщике Cron (`crontab -e`):
   ```cron
   */30 * * * * cd /var/www/sck && /usr/bin/python3 check_and_save.py >> /var/log/sck.log 2>&1
   ```

## 💻 Локальный запуск на компьютере

### Запуск веб-сайта локально:
```bash
py -m http.server 8080 --directory docs
```
Откройте в браузере: **[http://localhost:8080](http://localhost:8080)**.

### Запуск консольного чекера:
```bash
py checker.py
```
Скрипт протестирует ключи, выведет рейтинг ТОП-5 в консоль и сохранит:
* `working_keys.txt` — все ключи с разделением на пакеты по 60 штук.
* Папку `chunks/` с отдельными файлами `sck_keys_part_1.txt`, `sck_keys_part_2.txt`...

## 📖 Как подключаться к серверам (Инструкция для пользователя)

1. **Скопируйте ключ**:
   * На сайте нажмите **«Скопировать»** у нужного сервера или нажмите **«Скопировать 60 ключей»** в разделе пакетов.
2. **Откройте ваш клиент**:
   * В **Karing** нажмите кнопку **«+»** в правом верхнем углу → выберите **«Добавить из буфера обмена»**.
   * В **Hiddify** нажмите кнопку **«Новый профиль»** → **«Добавить из буфера обмена»**.
   * В **v2rayTUN** / **Streisand** нажмите иконку импорта из буфера.
3. **Подключитесь**:
   * Выберите добавленный сервер или включите автоматический выбор с наименьшим пингом.
   * Нажмите главную круглую кнопку подключения.
